ConsultEase: Automated Consultancy Management System
A full-stack web application built as a mini project for Internet Programming. The system helps manage consultancy project records in a college setting with features for authentication, project management, filtering, downloading, and automated notifications.

🔧 Tech Stack
Frontend: React.js

Backend: Node.js + Express.js

Storage: Excel (xlsx) file system

File Uploads: multer

Authentication: JWT

Testing: Thunder Client

✅ Features
🛡️ Secure Login/Register (College Email)

📥 Add Consultancy Projects with:

Title, Industry, Academic Year, Amounts

PI, Co-PI, Faculty Details

File Uploads: Agreement + Bill Settlement

🗂 View/Edit/Delete Projects (with auth check)

🔍 Filter + Download project data as Excel:

Academic Year

Minimum Amount

Faculty Name / Industry

🔔 Notifications:

New Projects (last 15 days)

Active Projects (last 60 days)

📁 Folder Structure
/frontend – React UI

/backend – Node.js server with Excel handling

🔑 .env Example
frontend/.env:

REACT_APP_API_URL=http://localhost:5000

🧪 How to Run
Start backend: cd backend && node server.js

Start frontend: cd frontend && npm start
